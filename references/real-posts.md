## Ссылки и UTM: как размечает канал

| Куда ведёт | Домен | Пример |
|---|---|---|
| Инструкция по функции | `faq-ru.kaiten.site` | почти каждый буллет дайджеста |
| Статья-дайджест недели | `faq-ru.kaiten.site/daydzhest-<даты>` | «Об исправленных ошибках — в статье» |
| Блог | `kaiten.ru/blog/...` | #1450 |
| Кейс на внешней площадке | `secrets.tbank.ru` | #1458, #1431 |
| Техническая статья | `habr.com/ru/companies/kaiten/...` | #1480 |
| Лендинг решения | `kaiten.ru/teams/...` | #1431 |
| Документы продукта | `hq.kaiten.ru/p/...` | #1465 |
| Код | `github.com` | #1465 |

**Реальный формат UTM канала:**

```
?utm_source=tg&utm_medium=social&utm_campaign=<ДДММ>
```

`utm_campaign` это дата публикации четырьмя цифрами: `1008`, `0307`, `0608`, `1308`,
`1908`, `2007`. Ставится **не на все ссылки**, а на переходы в блог, на лендинг
и на внешние площадки. Ссылки на базу знаний в дайджестах чаще идут без меток.
