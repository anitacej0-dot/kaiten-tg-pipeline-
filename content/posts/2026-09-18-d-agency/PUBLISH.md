## 1 · Текст поста

Скопировать целиком, включая эмодзи и переносы строк.

```
🎙 Как D-Agency ведет 16 проектов без проджект-менеджера?

D-Agency — агентство полного цикла из Санкт-Петербурга. В Кайтене команда работает больше четырех лет.

Раньше проектов было семь, и проджект-менеджер не успевал. Колонки на доске назывались по месяцам, и этап материала приходилось искать внутри карточки.

Доску перестроили по этапам: от запаса идей до публикации. А контроль передали автоматизациям:

🟣 карточка уходит к следующему специалисту — метка и упоминание появляются сами,
🟣 на этап отведено три дня, задержку видно по статусу,
🟣 без учета времени карточка не двигается дальше,
🟣 клиент молчит один-два дня — карточка уезжает на доску «На паузе».

Сейчас агентство ведет 16 проектов без проджект-менеджера, а статус проекта Игорь проверяет примерно за минуту.

> Для нас тут работает простое правило: если инструмент создан, чтобы экономить время, он не должен сам отнимать его.

Опытом делится Игорь Демидов, генеральный директор D-Agency.

📌 Главное собрали в карточках. Полный кейс — в статье.
```

## 2 · Форматирование в Телеграме

| Что | Как |
|---|---|
| Первая строка после 🎙 | **жирным** |
| `D-Agency`, `16 проектов`, `больше четырех лет` | **жирным** |
| `«На паузе»` | **жирным**, кавычки ёлочки |
| Блок после `>` | **цитатой** |
| `в статье` | **гиперссылка**, адрес ниже |
| Буллеты `🟣` | строчной буквой, через запятую, последний с точкой |

**Голого URL в посте быть не должно.** Ссылка вшивается в слова «в статье».

## 3 · Ссылка

```
https://kaiten.ru/blog/case-d-agency/?utm_source=tg&utm_medium=social&utm_campaign=1809
```

Метка `utm_campaign` это дата публикации четырьмя цифрами. **Если пост выйдет
не 18 сентября, поменять `1809` на свою дату**, иначе клики уедут в чужую кампанию.

**Опциональная вторая ссылка.** В статье лежит готовый шаблон пространства, собранный
по рассказу Игоря. Если решим звать на него, строка ставится последней, после кейса,
по образцу поста #1431:

```
👉 Забрать шаблон пространства из кейса
https://elli.kaiten.ru/p/0c6aa17d-2432-479a-8fd7-54b8c267ae57?utm_source=tg&utm_medium=social&utm_campaign=1809
```

С этой строкой длина вырастет до 1064 знаков, это на 14 знаков выше потолка типа.
Решение за редактором: кликов будет больше, длина уйдёт за диапазон корпуса.

**Для дизайнера рядом лежат те же шесть кадров в SVG** с живым текстом: Фигма
импортирует их слоями, шрифт и кегль правятся на месте.

python scripts/html-to-svg.py content/posts/2026-09-18-d-agency/img/*.html

Тени в SVG не переносятся: белая плашка со стикером 🚀 на обложке приедет без тени,
