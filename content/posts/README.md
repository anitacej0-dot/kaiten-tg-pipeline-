# Посты

Одна папка на пост: `content/posts/<YYYY-MM-DD>-<slug>/`.

```
2026-09-03-novaya-navigaciya/
  post.md          # фактура с источниками, ICP-сверка, варианты в блоках ```post
  PUBLISH.md       # готовое к публикации: чистый текст, ссылка, картинка, чек-лист
  ab-plan.json     # предсказание ДО публикации, факт после, калибровка и уроки
  img/             # HTML-макеты картинок и отрендеренные PNG
  scoring/         # отчёты скоринга по вариантам (по одному на вариант)
```

Правила:

- **Варианты лежат в блоках ` ```post `** внутри разделов `## Вариант N · <тип>`.
  **Тип поста в заголовке раздела обязателен** (дайджест, обновление, кейс):
  по нему валидатор включает проверки типа. Валидатор смотрит только блоки ```post,
  всё остальное в файле для людей.
- **`ab-plan.json` заводится до публикации.** Без предсказания калибровать нечего,
  а задним числом предсказания не переписываются.
- **Картинки рендерятся из HTML**, PNG не правится руками: следующая версия соберётся заново.
  Формат по типу поста берётся из [../../docs/VISUALS.md](../../docs/VISUALS.md):
  обложка и карусель. Число карточек совпадает с числом, обещанным в тексте.
- **Раздел «Фактура»** в `post.md` обязателен: дословные названия из базы знаний,
  ссылка на статью-источник и отдельный список «чего на странице нет».
- После выхода поста строка добавляется в [../plan.md](../plan.md), таблица «Что вышло».

Папка `2026-09-01-zavershennye-iteracii` показывает формат целиком: фактура
со списком «чего на странице нет», четыре варианта одного типа, отчёт проверки,
карусель из обложки и трёх карточек, предсказание в `ab-plan.json`.
Валидатор на ней даёт 0 нарушений.
