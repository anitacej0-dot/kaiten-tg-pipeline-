# Визуалы канала: форматы, композиции, токены

> Разобрано по **18 реальным макетам** канала, присланным 03.09.2026: обложки дайджеста,
> карусель дайджеста, обложка и карусель поста-обновления, серия «как сделать».
> Дизайн-система: [ha1ex/content_zavod, design-system/kaiten-v01](https://github.com/ha1ex/content_zavod/tree/main/design-system).
>
> **Главное отличие от прежней версии этого файла:** канал не публикует одну картинку
> к посту. Канал публикует **карусель** из обложки и карточек, и посты прямо на неё
> ссылаются: «В карточках показали, как собрать дашборд за 5 шагов», «Подробнее — в карточках».

## Правило редакции на всех макетах

**Буквы «ё» на иллюстрациях нет. Всегда «е».** Правило редполитики, действует и в тексте,
и в графике. См. [../references/editorial-policy.md](../references/editorial-policy.md).

⚠️ В присланных макетах «ё» встречается: «Счётчик», «Копия создаётся», «завершённые
задачи». Либо правило введено позже этих макетов, либо это ошибки вёрстки. Стоит
проверить и поправить исходники.

**Имя бренда на картинках - `Kaiten` латиницей.** В тексте поста - `Кайтен` кириллицей.

## Формат 1 · Обложка дайджеста

Единственный декоративный макет канала: **без скриншота**, чистая графика.

- **Размеры:** встречаются и `1280×720` (16:9), и `1280×1280` (1:1).
- **Фон:** очень светлый лавандовый.
- **Декор:** сиреневые скруглённые квадраты разного размера, жёлтые линии-завитки,
  фиолетовые точечные сетки 5×5. Раскиданы по углам, в центр не лезут.
- **Заголовок по центру:** «Обновления» фиолетовым, «и исправленные ошибки» тёмным,
  где «ошибки» снова фиолетовым. Двухцветность работает на всех макетах канала.
- **Пилюля-подпись** `violet-12` со словом «дайджест» строчными.
- **Пилюля с датой** жёлтая, с иконкой календаря: «17–21 августа».
  Диапазон через **короткое тире** `–`, по редполитике.
- **Логотипа нет.**

## Формат 2 · Карточка карусели дайджеста

Одна карточка на одно обновление. Идут следом за обложкой.

```
┌──────────────────────────────────────┐
│ ФАЙЛЫ                     ← кикер     │  капс, violet-100
│                                       │
│ Все файлы пространства                │  neutral-900
│ в одном месте                         │  violet-100
│                                       │
│ ┌───────────────────────────────────┐ │
│ │  скриншот интерфейса              │ │  белая карточка, рамка
│ │  с фиолетовой стрелкой-указателем │ │  скругление 2xl
│ └───────────────────────────────────┘ │
│                                       │
│ Новый раздел «Файлы»: ищите по        │  neutral-600, 2-3 строки
│ названию, фильтруйте по типу.         │
│                                       │
│ [Kaiten]                        ( → ) │  логотип слева, кружок справа
└──────────────────────────────────────┘
```

- **Кикер** это раздел продукта капсом: `ФАЙЛЫ`, `СПРАВОЧНЫЙ ЦЕНТР`, `ИТЕРАЦИИ`, `ВЛОЖЕНИЯ`.
  Статус беты пишется прямо в кикере: `АДМИНИСТРИРОВАНИЕ · BETA`.
- **Скриншот** иногда лежит на подложке `violet-12`, иногда прямо на фоне.
  Конфиденциальные данные (имена, файлы) **заблюрены**.
- **Стрелки-указатели** фиолетовые, тонкие, показывают на конкретный элемент.
- **Подпись** разговорная, объясняет пользу, а не повторяет заголовок.
- **Счётчика карточек нет.**

## Формат 3 · Обложка поста-обновления

- **Крупный скриншот под наклоном** занимает верхние две трети.
- **Плашка-счётчик** `violet-100`: «📊 4 обновления».
- **Крупный заголовок** в две строки: «Что нового в дашбордах», двухцветный.
- **«Листайте →»** справа, приглашение к карусели.
- Фон лавандовый градиент.

## Формат 4 · Карточка карусели обновления

Как формат 2, с одним отличием: **справа вверху счётчик** `1 / 4`, `2 / 4` серым.
Кикер здесь это название самого изменения (`КОПИРОВАНИЕ ВИДЖЕТОВ`, `НАБОРЫ ФИЛЬТРОВ`,
`СОСТОЯНИЕ КАРТОЧКИ`), а не раздел продукта.

Счётчик нужен, потому что пост обещает конкретное число: «📊 4 обновления».
Число на обложке и число карточек обязаны совпадать.

## Формат 5 · Обложка серии «как сделать»

- **Логотип Kaiten сверху слева** (в дайджест-карусели он внизу, здесь вверху).
- **Крупный заголовок** «Как собрать дашборд», двухцветный.
- **Подзаголовок** серым, 2-3 строки, объясняет что получит читатель.
- **Пилюля** `violet-12` с обещанием объёма: «• 5 шагов от пустой страницы до готовой панели».
- **Скриншот снизу**, намеренно обрезан краем кадра.

## Формат 6 · Карточка шага

```
┌──────────────────────────────────────┐
│ [Kaiten]        ( Как собрать дашборд )│  логотип слева, пилюля серии справа
│                                       │
│ ┌───┐  ШАГ 1                          │  бейдж violet-100, белая цифра
│ │ 1 │  Создайте дашборд               │  заголовок neutral-900
│ └───┘                                 │
│ ┌───────────────────────────────────┐ │
│ │ скриншот с кружками 1, 2          │ │  нумерованные указатели
│ │ и стрелками                       │ │
│ └───────────────────────────────────┘ │
│                                       │
│ Раздел «Дашборды» находится в левой   │  neutral-600
│ панели. Нажмите «Новый дашборд».      │  названия элементов жирным
└──────────────────────────────────────┘
```

- **Номер шага** в фиолетовом скруглённом квадрате, белая цифра.
- **Пилюля серии** справа вверху повторяется на каждой карточке.
- **Нумерованные кружки на скриншоте** показывают порядок действий внутри шага.
- **В подписи названия кнопок и разделов выделены** жирным и фиолетовым:
  «Раздел **«Дашборды»**… нажмите **«Новый дашборд»**».
- **Стрелки → в подвале нет**, серия закрытая.
- **Вариант без скриншота:** шаг 3 показывает 4 плитки с иконками вместо экрана,
  когда объяснять надо выбор из вариантов, а не место на экране.

## Формат 7 · Видео

Для поста-обновления вместо карусели может идти **видео-скринкаст**. Пример лежит
у редакции (`Пример.MOV`, около 1 МБ). Так был оформлен и пост про запуск итераций
от 10.07.2026: GIF-скринкаст интерфейса над текстом.

Правило выбора: **видео**, когда важно показать движение и последовательность в одном
экране. **Карусель**, когда обновлений несколько или шагов больше трёх.

## Какой формат к какому типу поста

| Тип поста | Обложка | Карточки | Счётчик |
|---|---|---|---|
| **Дайджест** | формат 1, декоративная | формат 2, по одной на обновление | нет |
| **Обновление и фича** | формат 3, скриншот под наклоном | формат 4 | да, `N / N` |
| **Обновление, одна функция** | формат 7, видео | нет | нет |
| **Как сделать** | формат 5 | формат 6, по одной на шаг | номер шага |
| **Кейс** | ⚠️ макетов не присылали | «Главное собрали в карточках» | ? |

⚠️ **Пробел: макеты кейсов.** Посты #1458 и #1431 ссылаются на карточки, но их
оформление не разобрано. Нужны примеры.

## Общие правила

- **Одна мысль на карточку.** Заголовок до 6 слов, подпись до 3 строк.
- **Заголовок двухцветный:** начало `neutral-900`, смысловая часть `violet-100`.
  Делить по смыслу, а не по длине строки.
- **Подпись не повторяет заголовок**, а добавляет: что это даёт и где лежит.
- **Скриншот читаемый без увеличения.** Требование редполитики: «Читатель должен сразу
  понять, что ему показывают, без увеличения экрана».
- **Конфиденциальное блюрим** - имена, почты, названия файлов клиентов.
- **Точек в заголовках нет.**
- **Кавычки «ёлочки».**
- Никаких кикеров-надзаголовков вроде «новинка» и «только сейчас».

## Рендер

Макеты собираются из HTML в `templates/img/`, рендерятся в PNG 2× через headless Chrome:

```bash
node scripts/render-images.mjs content/posts/<slug>/img/*.html
```

Если Node на машине нет, тот же Chrome вызывается напрямую:

```bash
python scripts/render-images.py content/posts/<slug>/img/*.html
```

Размер кадра берётся из атрибутов `data-w` и `data-h` на `<body>`.
Форматы канала: `1080×1080` для карточек карусели, `1280×720` для широкой обложки дайджеста.
