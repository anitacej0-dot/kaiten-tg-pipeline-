# Визуалы: правила, палитра композиций, рендер

> Картинка делается **только победителю**. Рисовать иллюстрацию к тексту, который
> не прошёл отбор, нет смысла.

## 1 · Токены Kaiten v01

Берутся из дизайн-системы `ha1ex/content_zavod`, папка `design-system`
(`tokens.json` + `design-system.html`). Продублированы в `templates/img/kaiten.css`:

| Токен | Значение | Где применяется |
|---|---|---|
| `--violet` | `#7d4ccf` | акценты, CTA, маркеры, крупные цифры |
| `--violet-12` | `#efe9f9` | подложки блоков, плитки, выделения |
| `--text` | `#2d2d2d` | основной текст |
| `--border` | `#e0e0e0` | границы карточек и разделители |
| `--bg` | `#ffffff` | фон кадра |
| шрифт | Roboto | заголовки 700-900, текст 400-700 |
| радиусы | 8-16 px | карточки, плитки, кнопки |

⚠️ Макеты инфлюенс-репо собраны на **Inter**, а дизайн-система Кайтена использует
**Roboto**. Здесь всё приведено к Roboto. Если картинка идёт в общий поток материалов
Кайтена, шрифт не менять.

## 2 · Правило разнообразия композиций

**⛔ Запрещён один шаблон на все картинки.** Прецедент из инфлюенс-репо: девять картинок
подряд по схеме «заголовок + окно с графиком + CTA». Композиция предыдущего поста
не повторяется (окно 3 поста, см. [CONTENT-PLAN.md](CONTENT-PLAN.md)).

Палитра композиций:

| Композиция | Файл-шаблон | Когда работает |
|---|---|---|
| **Крупная цифра или факт** на всю площадь | `big-number.html` | кейс, метрика, результат |
| **До и после**, две панели | `before-after.html` | миграция, наведение порядка |
| **Сценка-чат**, пузыри диалога | `chat.html` | боль роли, узнаваемая ситуация |
| **Интерфейс продукта**, схематичная доска | `interface.html` | разбор фичи, «как это выглядит» |
| **Сетка плиток** 4-6 штук с эмодзи | `grid.html` | дайджест, список возможностей |
| **Чек-лист** с галочками | `checklist.html` | «как выбрать», «что проверить» |
| **Таймлайн 1→2→3** | `steps.html` | инструкция, методология |

Внутри одного набора картинок к посту допускается смешение, но подряд идущие посты
канала обязаны отличаться композицией.

## 3 · Форматы

| Размер | Назначение |
|---|---|
| 1080×1080 | стандарт для поста в канале |
| 1080×1350 (4:5) | занимает больше экрана, для важных постов |
| 1200×675 (16:9) | превью ссылки, шапка статьи |

Размер берётся из самого макета: атрибуты `data-w` и `data-h` на `<body>` или размеры
`.frame` в CSS. Один и тот же исходник нельзя случайно отрендерить в чужом формате.

## 4 · Правила самой картинки

- **Считывается за 1 секунду.** Одна мысль на кадр. Если нужно вчитываться, картинка не работает.
- **Без кикеров** и рекламных надзаголовков («новинка», «только сейчас»).
- Текста мало: заголовок до 6 слов, в списке до 6 строк.
- Цифра крупнее слов вокруг неё, если цифра и есть сообщение.
- Логотип в подвале, не в заголовке.
- Эмодзи в визуале допустимы, если тон поста это позволяет.
- Картинка не дублирует первую строку поста дословно, а добавляет к ней.

## 5 · Рендер

```bash
node scripts/render-images.mjs templates/img/big-number.html
node scripts/render-images.mjs content/posts/<slug>/img/*.html
```

HTML → PNG через headless Chrome в 2× (retina). PNG кладётся рядом с HTML под тем же именем.
Chrome ищется автоматически: системный, Chrome for Testing из кэша `@puppeteer/browsers`,
либо путь в переменной `CHROME`. Первый запуск на машине:

```bash
npx @puppeteer/browsers install chrome@stable
```

Рабочий цикл: копируешь шаблон в папку поста, меняешь текст, рендеришь, смотришь PNG.
Правки текста в макете, а не в PNG - иначе следующая версия соберётся заново с ошибкой.
