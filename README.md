# Kaiten TG · конвейер постов собственного канала

Репозиторий-конвейер для канала [@kaiten_ru](https://t.me/kaiten_ru): тема на входе,
готовый пост с картинкой и обоснованием на выходе, факт после публикации на входе
следующего поста.

Собран из инфлюенс-платформы [kaiten-influence](https://github.com/cryptoyoginya/kaiten-influence)
(Кристина, Кайтен): оттуда взяты рубрика тона, хук-банк, каталог жанров, скоринг
на 6 линз, панель персон и рендер картинок. Выброшено всё про закупку у блогеров:
договоры, ERID, CPV/CPL, скоринг канала, переговоры. Добавлено то, чего в инфлюенсе
нет: рубрикатор своего канала, контент-план и антиповторы между постами.

**Принцип тот же: чего нет в данных, того нет в посте.**

## Точка входа

```
/post <тема>
```

Скилл `.claude/skills/post/SKILL.md` ведёт агента по [docs/RUNBOOK.md](docs/RUNBOOK.md):
тема → фактура → 3-5 вариантов разных жанров → гейты → скоринг → правки → картинка →
валидатор → рекомендация → публикация → факт T+24/T+72 → калибровка.

**Два обязательных согласования с человеком:** (1) угол и фактура до генерации,
(2) финальный текст до публикации. Всё между ними агент делает сам.

## Скрипты

```bash
python scripts/validate-post.py content/posts/<slug>/post.md   # механическая проверка текста
python scripts/check-facts.py                                  # долги по факту после публикации
node scripts/render-images.mjs templates/img/big-number.html   # HTML → PNG 2×
```

Валидатор ловит длинные тире, обороты «не X, а Y» и «не только, но и», вклеенные
инлайн-стили из копипаста, отсутствие ссылки, недостаток продуктовой конкретики
и клонов внутри сета по 3-граммам. Любой FAIL правится до нуля нарушений.

## Первый запуск

```bash
node --version          # нужен Node 18+
python --version        # нужен Python 3.10+
npx @puppeteer/browsers install chrome@stable   # один раз, для рендера картинок
```

Ничего ставить через npm install не нужно: скрипты работают на стандартной библиотеке.

## Чего здесь нет

Скоринг это LLM-судья с рубрикой, а не ML-модель. «Обучение» здесь означает
калибровку рубрики, персон и голос-профиля на размеченных данных по петле
«предсказание → факт → правка». Пока фактов мало, баллы это структурированное
мнение, а не измерение. Именно поэтому шаг 10 (факт) обязательный.
