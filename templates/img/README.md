# Шаблоны карточек канала

Собраны по 24 реальным макетам канала. Анатомия каждого формата и правила -
[../../docs/VISUALS.md](../../docs/VISUALS.md).

**У обновления три способа иллюстрации, карусель лишь один из них:**
одиночная картинка (`update-single`), карусель (`update-cover` + `update-card`
либо `howto-cover` + `howto-step`) и гифка-скринкаст, которая снимается вне
репозитория. Правило выбора: сколько экранов нужно, чтобы понять.

| Шаблон | Формат | Когда берём |
|---|---|---|
| `digest-cover.html` | обложка дайджеста | декоративная, без скриншота, жёлтая плашка с датами |
| `digest-card.html` | карточка дайджеста | одна на обновление, кикер = раздел продукта, счётчика нет |
| `update-cover.html` | обложка обновления | скриншот под наклоном, плашка «N обновлений», «Листайте →» |
| `update-card.html` | карточка обновления | счётчик `N / N`, кикер = название изменения |
| `update-single.html` | **одиночная картинка к обновлению** | когда обновление одно и укладывается в один экран: счётчика и стрелки нет |
| `howto-cover.html` | обложка инструкции | логотип сверху, пилюля с числом шагов, скриншот обрезан краем |
| `howto-step.html` | карточка шага | бейдж с номером, пилюля серии справа, стрелки в подвале нет |
| `webinar-cover.html` | **обложка вебинара и анонса события** | плашка с датой слева, плашка типа справа, эмодзи-стикер на углу скриншота, декор: точки, дуга, зигзаг |
| `case-cover.html` | обложка кейса | фото вместо скриншота, цитата героя заголовком, эмодзи-стикер |
| `case-card.html` | карточка кейса | счётчик `01 / 04`, кикер = роль карточки в истории |
| `case-final.html` | финал кейса | «Вывод» вместо счётчика, галочки, фиолетовая CTA-плашка |
| `guide-cover.html` | **обложка статьи с экспертами** | 4:5, сиреневый фон, белая пилюля вместо кикера, ряд фото экспертов, логотипа нет |
| `guide-card.html` | **карточка статьи с экспертами** | 4:5, белые плашки с номерами, ни счётчика, ни логотипа |

## Рабочий цикл

```bash
cp templates/img/update-card.html content/posts/<slug>/img/01-kopirovanie.html
cp templates/img/kaiten.css templates/img/kaiten-logo.svg content/posts/<slug>/img/
# поменять текст, вставить скриншот вместо <div class="stub">
python scripts/render-images.py content/posts/<slug>/img/*.html   # PNG 2x к публикации
python scripts/html-to-svg.py  content/posts/<slug>/img/*.html    # SVG дизайнеру в Фигму
```

**Шрифты.** Заголовки - Raleway Bold, текст и подписи - Onest. Раскладка по классам
в `kaiten.css`, переменные `--font-display` и `--font-text`.

Скриншот вставляется вместо заглушки:

```html
<div class="shot pad"><img src="screenshot.png" alt=""/></div>
```

## Что менять нельзя

- **Букву «ё» не ставим нигде.** Всегда «е». Правило редакции, проверяется перед сдачей.
- **Стили в `kaiten.css` не трогаем** при вёрстке конкретного поста. Нужен новый приём -
  добавляем класс в CSS и описываем его в `docs/VISUALS.md`, а не пишем инлайн-стиль.
- **Точку в заголовке не ставим.**
- **Кавычки только «ёлочки».**
- Логотип `Kaiten` латиницей.

## Полезные классы

| Класс | Что делает |
|---|---|
| `.frame.lav` | лавандовый фон вместо белого |
| `.h .hl` | вторая половина заголовка фиолетовым |
| `.lead b` | жирный акцент в подзаголовке |
| `.shot.pad` | скриншот на подложке `violet-12` |
| `.shot.violet` | фиолетовая рамка 3 px, для кейсов и обложек |
| `.cap b` | название кнопки в подписи, жирное и фиолетовое |
| `.sticker` | эмодзи в белой плашке, кладётся в контейнер с `position:relative` |
| `.quote` | плашка-цитата героя |
| `.numlist` | нумерованные белые карточки с кружками |
| `.rows .r.off` | пункт пунктирной рамкой, «неактивный» |
| `.checks` | список галочками |
| `.ctabar` | фиолетовая плашка призыва на всю ширину |
| `.crop` | кадр внутри `.shot`: показывает кусок исходника, сам PNG не режем |
| `.herorow` | портрет героя 460 px с именем и должностью на обложке кейса |
| `.frame.lilac` | сиреневый фон кадра 4:5 для статьи с экспертами |
| `.deco.blob` | органические светлые пятна по углам сиреневого кадра |
| `.steps` | список белыми плашками: круг с номером слева, текст справа |
| `.note` | белая карточка-мысль на сиреневом фоне |
| `.quotecard` | реплика эксперта: фото слева, цитата и подпись справа |
| `.faces` | ряд фото экспертов на обложке |
| `.accent` | вывод или вопрос фиолетовым внизу карточки |
| `.pill.soft` / `.solid` / `.sun` | пилюли: сиреневая, фиолетовая, жёлтая |
